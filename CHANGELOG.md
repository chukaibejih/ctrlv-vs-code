# Change Log

All notable changes to the "CtrlV Code Sharing" extension will be documented in this file.

## [1.1.0] - 2025-04-30

- URI protocol handler for "Open in VS Code" functionality
- Support for opening code snippets directly from the CtrlV website
- Telemetry for tracking usage of the new feature


## [1.0.1] - 2025-03-22

- Updated telemetry endpoint from localhost to production server
- Fixed compatibility issues with older VS Code versions
- Improved error handling and stability
- Updated documentation to clarify TypeScript React (TSX) file support status

## [1.0.0] - 2025-03-15

- Initial release
- Share selected code via CtrlV
- Share entire files via CtrlV
- Configure expiration time (1h, 24h, 7d)
- One-time view option
- Context menu integration
- Keyboard shortcut support (Ctrl+Alt+V / Cmd+Alt+V)
